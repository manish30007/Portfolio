## Run Locally

Clone the repository:

```bash
git clone https://github.com/manish30007/Portfolio.git
cd Portfolio
```

Open `index.html` directly in your browser or serve it using any local HTTP server.

For example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
